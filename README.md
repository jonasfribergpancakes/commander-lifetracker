# Commander Lifetracker

Lifetracker för Magic: The Gathering Commander, 2–5 spelare. Liv, commander-skada, poison, commander tax, turordning och speltid.

Öppna appen: https://jonasfribergpancakes.github.io/commander-lifetracker/

Installera på iPhone: öppna länken i Safari, tryck på dela-knappen och välj "Lägg till på hemskärmen".
